# Mobile Sales Analysis Dashboard | Power BI
An interactive Power BI dashboard analyzing mobile sales, customer ratings, payment methods, and monthly sales trends.

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze mobile phone sales performance, customer ratings, payment preferences, and monthly quantity trends.

The dashboard helps users understand sales performance across different brands, mobile models, states, and payment methods.

## Project Objectives

* Analyze total sales and quantity sold.
* Track monthly sales quantity trends.
* Compare sales performance across mobile brands.
* Identify top-performing states and mobile models.
* Understand customer ratings and payment preferences.
* Present key business metrics using an interactive dashboard.

## Tools & Technologies

* Microsoft Power BI
* Data Visualization
* Data Analysis
* Data Cleaning and Transformation
* Interactive Filters and Slicers

## Key Dashboard Insights

* **Total Quantity:** Approximately 19K units.
* **Total Sales:** Displayed as 769M in the dashboard.
* **Transactions:** Approximately 4K.
* **Average:** Displayed as 40K.
* **Monthly Quantity:** July has the highest displayed quantity, at 1,700.
* **Top States by Sales:** Delhi, Mumbai, and Ranchi.
* **Top Mobile Models:** iPhone SE, OnePlus Nord, and Galaxy Note 20.
* **Customer Ratings:** A rating of 5 has the highest displayed count.

## Dashboard Features

* KPI cards for key business metrics.
* Monthly quantity trend analysis.
* Brand-wise sales and quantity comparison.
* Payment method analysis.
* State-wise sales comparison.
* Top mobile models by sales.
* Customer rating distribution.
* Month, brand, and payment method filters.
